# 가격조사 도우미 사용 가이드

이 앱은 국군복지단 가격조사 현장에서 매장 방문, 물품 확인, 가격 입력, 사진 정리, 결과 내보내기를 한 번에 처리하기 위한 웹앱입니다.

입력 자료와 조사 결과는 서버 DB가 아니라 이 기기의 브라우저 저장공간에 보관됩니다. 다른 기기에서 이어서 작업하려면 반드시 전체 백업 파일을 내려받아 복원해 주세요.

## 1. 시작 전 준비

준비할 파일:

- 조사표 엑셀
- 업체 연락처 엑셀
- 바코드 이미지 엑셀

권장 준비:

- 현장에 나가기 전 PC에서 자료 업로드와 담당매장 설정을 먼저 완료합니다.
- 담당매장 위치를 미리 가져오면 지도와 거리순 정렬을 더 편하게 쓸 수 있습니다.
- 작업 기기를 바꿀 가능성이 있으면 전체 백업을 자주 내려받습니다.

## 2. 자료 업로드

처음 실행하면 자료 업로드 화면이 열립니다.

1. 조사표 엑셀을 선택합니다.
2. 업체 연락처 엑셀을 선택합니다.
3. 바코드 이미지 엑셀을 선택합니다.
4. 자료 분석을 시작합니다.

분석이 끝나면 지역, 매장, 물품 목록이 이 브라우저에 저장됩니다.

주의:

- 자료를 다시 분석하면 기존 입력값이나 사진이 초기화될 수 있습니다.
- 새 자료로 다시 시작하기 전에는 전체 백업을 먼저 내려받는 것이 안전합니다.
- 같은 휴대폰이라도 Chrome, 네이버앱, 삼성 인터넷은 서로 저장공간이 다릅니다.

## 3. 메인

메인에서는 지역별 진행 상황을 확인합니다.

지역 카드에서 볼 수 있는 정보:

- 지역명
- 상세지역
- 담당부서
- 전체 매장/물품 진행률
- 담당매장 진행률

버튼:

- 작업: 해당 지역의 매장리스트로 이동
- 엑셀: 지역별 조사결과 엑셀 다운로드
- 사진: 지역별 사진 ZIP 다운로드
- 백업: 지역별 백업 다운로드

3점 메뉴:

- 담당매장 관리

전체 지도 버튼을 누르면 조사처 참고 지도를 외부 지도에서 확인할 수 있습니다.

## 4. 담당매장 관리

담당매장 관리는 내가 실제로 방문할 매장만 추려서 보는 기능입니다.

기본값은 전체 미선택입니다. 필요한 매장을 체크한 뒤 저장하면 매장리스트와 매장지도에는 체크한 담당매장만 표시됩니다.

할 수 있는 일:

- 담당매장 선택/해제
- 전체 선택/전체 해제
- 위치 없는 매장만 위치 가져오기
- 전체 위치 가져오기

위치 가져오기는 인터넷이 필요합니다. 위치를 가져오면 매장지도와 거리순 정렬에 사용할 수 있습니다.

## 5. 매장리스트

매장리스트는 실제 방문 매장을 고르는 화면입니다.

검색할 수 있는 항목:

- 매장명
- 주소
- 물품명
- 물품코드
- 바코드
- 담당자

필터:

- 전체
- 미완료
- 완료
- 사진누락

정렬:

- 이름순
- 품목 많은 순
- 미완료 많은 순
- 거리순

거리순은 내 위치와 매장 위치가 모두 있을 때 사용할 수 있습니다. 오른쪽 아래의 내 위치 버튼을 누르면 현재 위치가 갱신됩니다.

매장 카드에서 할 수 있는 일:

- 담당자 정보 확인
- 입력 화면으로 이동
- 3점 메뉴에서 외부 지도 열기
- 3점 메뉴에서 매장지도에서 보기

완료된 매장은 카드 색상과 진행률로 구분됩니다.

## 6. 매장지도

매장지도는 담당매장을 지도 위에서 확인하는 화면입니다.

지도에서 볼 수 있는 것:

- 내 위치
- 담당매장 마커
- 완료/미완료 상태
- 선택한 매장의 간단 정보 카드

사용 방법:

1. 내 위치 버튼을 눌러 현재 위치를 갱신합니다.
2. 지도에서 매장 마커를 누릅니다.
3. 아래 카드가 선택한 매장으로 바뀝니다.
4. 담당자 정보 또는 입력 버튼을 눌러 작업합니다.

매장리스트의 3점 메뉴에서 `매장지도에서 보기`를 누르면 해당 매장을 지도에서 바로 확인할 수 있습니다.

## 7. 매장정보

매장정보는 방문 매장의 기본 상태를 입력하는 화면입니다.

입력 순서:

1. 매장 전경사진을 촬영하거나 선택합니다.
2. 이미 찍은 전경사진이 있으면 기존 사진 사용을 눌러 재사용할 수 있습니다.
3. 매장 상태를 선택하고 저장합니다.
4. 방문 조사일을 확인합니다.
5. 조사 입력 버튼을 눌러 물품리스트로 이동합니다.

매장 상태:

- 미확인
- 영업 중
- 폐업
- 임시휴업

전경사진이 없는 매장은 기본적으로 미확인입니다. 영업 중으로 확인된 매장만 물품 가격정보 저장을 진행하는 흐름입니다.

폐업이나 임시휴업으로 처리하면 해당 매장의 물품에 일괄 반영됩니다.

## 8. 물품리스트

물품리스트에서는 매장 안의 조사 물품을 확인합니다.

카드에서 볼 수 있는 정보:

- 물품코드
- 물품명
- 바코드
- 기준가격
- 조사가격
- 적격/부적격
- 사진누락 여부
- 사진 미리보기

검색:

- 물품명
- 바코드
- 물품코드
- 담당자

버튼:

- 입력: 가격정보 화면으로 이동
- 바코드: 바코드/POS 확인 모달 열기

미진열 상품을 모아 확인하려면 필터에서 미진열 조건을 사용합니다.

## 9. 바코드 / POS 확인

바코드 버튼을 누르면 해당 물품의 바코드 이미지를 크게 볼 수 있습니다.

이 기능은 미진열 상품을 계산대에서 연속으로 POS 조회할 때 사용합니다.

사용 흐름:

1. 물품리스트에서 미진열 상품을 필터링합니다.
2. 바코드 버튼을 누릅니다.
3. POS에서 바코드를 확인합니다.
4. 입력 버튼을 누르면 가격정보 화면의 상태/POS 입력 위치로 이동합니다.
5. 저장 후 다시 바코드 확인 흐름으로 돌아갈 수 있습니다.
6. 이전/다음 버튼으로 다음 상품을 계속 확인합니다.

바코드 이미지는 바코드 이미지 엑셀에서 물품코드와 같은 행의 이미지를 가져옵니다.

## 10. 가격정보 입력

가격정보 화면은 물품별 조사 내용을 저장하는 핵심 화면입니다.

### 담당자 정보

담당자명과 연락처를 확인합니다. 연락처를 누르면 바로 전화 연결됩니다.

### 국군복지단 제시정보

참고용 기준 정보입니다.

- 물품코드
- 제조사
- 물품명
- 규격
- 기준가격
- 바코드
- 상세주소

### 실물 확인

진열여부를 먼저 선택합니다.

- 진열여부 O: 규격일치, 바코드일치 입력 가능
- 진열여부 X: 상태 입력 영역에서 미진열/미판매, POS 조회 여부 입력

### 상태

진열여부가 X일 때 주로 입력합니다.

- 바코드 등록 여부
- 판매여부
- POS 조회 여부

POS 조회 여부를 바꾸면 비고의 POS 관련 문구도 함께 정리됩니다.

### 사진자료

사진 종류:

- 제품진열사진
- 제품정보사진
- POS/영수증사진

제품진열사진은 가격표와 진열상품이 같이 보이도록 촬영합니다.
제품정보사진은 상품 후면 정보와 바코드가 같이 보이도록 촬영합니다.
POS/영수증사진은 진열사진으로 가격 확인이 어렵거나 POS 조회가 필요한 경우 촬영합니다.

사진을 올리면 작은 미리보기가 표시됩니다. 잘못 올렸으면 지우고 다시 촬영할 수 있습니다.

자동 인식:

- 제품정보사진: 바코드 자동 비교
- 제품진열사진/POS사진: 가격 후보 자동 추출

인식된 가격 후보는 가격 입력칸 근처에 칩으로 표시되며, 누르면 바로 입력됩니다.

### 가격

입력 항목:

- 정상가
- 할인 여부
- 행사 여부
- 할인가
- 할인기간
- 구두 확인
- 시작일 / 종료일
- 기간 구분

가격은 숫자로 입력하면 천 단위 콤마가 자동 표시됩니다.

기준가격과 조사가격을 비교해 정상/주의 문구가 바로 표시됩니다. 조사가격이 기준가격보다 낮으면 부적격 가능성이 있으므로 다시 확인해야 합니다.

### 특이사항

비정상진열 여부와 비고를 입력합니다.

자주 쓰는 문구:

- 폐점
- 품절
- 재고 소진
- 재입고 예정
- 1+1 행사
- 임시휴업
- 판매처 미협조
- 가격 수기 입력

문구 칩은 다시 누르면 제거됩니다. 직접 입력한 비고는 사용자가 직접 수정합니다.

## 11. 저장과 이동

가격정보 화면에서는 저장 버튼을 눌러야 입력값이 저장됩니다.

하단 고정 바:

- 목록
- 저장
- 다음

저장하지 않고 목록이나 다음으로 이동하려고 하면 입력 내용이 사라질 수 있다는 안내가 표시됩니다.

저장 후:

- 다음 미등록 물품으로 이동할 수 있습니다.
- 해당 매장의 모든 물품이 완료되면 매장리스트로 돌아갈지 선택할 수 있습니다.

## 12. 검증

검증 화면에서는 입력 규칙보다 누락과 확인이 필요한 항목을 빠르게 확인합니다.

확인 대상:

- 미완료 물품
- 사진누락 물품
- 미진열 물품
- 특이사항 입력 물품
- 부적격 가능 물품

항목을 누르면 해당 가격정보 화면으로 이동합니다.

## 13. 내보내기

메인에서 지역별로 내려받을 수 있습니다.

엑셀:

- 조사표 양식에 맞춰 결과를 생성합니다.
- 저장된 조사값, 조사일, 특이사항, 가격판단을 포함합니다.

사진 ZIP:

- 물품코드 기준 파일명으로 생성됩니다.

파일명 규칙:

- `물품코드.1.jpg`: 매장 전경사진
- `물품코드.2.jpg`: 제품진열사진
- `물품코드.3.jpg`: 제품정보사진
- `물품코드.4.jpg`: POS/영수증사진

백업:

- 지역 백업은 해당 지역만 저장합니다.
- 전체 백업은 모든 지역, 매장, 물품, 사진, 설정을 저장합니다.

## 14. 다른 기기로 옮기기

다른 휴대폰이나 PC에서 이어서 작업하려면 전체 백업을 사용합니다.

1. 기존 기기에서 전체 백업을 내려받습니다.
2. 새 기기에서 앱을 엽니다.
3. 백업/복원 화면에서 전체 백업 파일을 복원합니다.
4. 지역, 담당매장, 입력값, 사진이 복원되었는지 확인합니다.

백업 파일은 조사 데이터 전체가 들어 있으므로 별도 보관에 주의해 주세요.

## 15. 저장공간 확인

메뉴에서 저장공간을 확인할 수 있습니다.

확인 항목:

- 저장 사진 수
- 사용 중 용량
- 여유 공간

사진이 많아지면 백업과 ZIP 생성 시간이 길어질 수 있습니다. 조사 중에는 지역별 백업이나 전체 백업을 자주 내려받는 것이 안전합니다.

## 16. 문제 해결

파일이 휴대폰에서 안 보일 때:

- 파일이 실제 기기 저장공간이나 클라우드 앱에 내려받아져 있는지 확인합니다.
- 같은 파일이라도 앱별 파일 선택기에서 보이는 위치가 다를 수 있습니다.

지도 타일이 회색으로 보일 때:

- 인터넷 연결을 확인합니다.
- 확대/축소를 한 번 바꿔 봅니다.
- OpenStreetMap 타일 응답 상태에 따라 일시적으로 늦게 표시될 수 있습니다.

위치가 안 잡힐 때:

- 브라우저 위치 권한을 허용합니다.
- 내 위치 버튼을 다시 누릅니다.
- 실내에서는 GPS가 느리게 잡힐 수 있습니다.

바코드 이미지가 안 맞을 때:

- 바코드 이미지 엑셀을 올바른 파일로 다시 업로드합니다.
- 물품코드와 같은 행의 바코드 이미지가 맞는지 원본 엑셀을 확인합니다.
- 필요하면 전체 백업 후 자료를 다시 분석합니다.

데이터가 갑자기 없어 보일 때:

- 같은 브라우저로 접속했는지 확인합니다.
- 앱 링크가 바뀌면 저장공간이 달라질 수 있습니다.
- 백업 파일이 있으면 복원합니다.

## 17. 현장 사용 팁

- 출발 전 담당매장을 먼저 체크합니다.
- 가능하면 위치 가져오기를 미리 실행합니다.
- 매장 도착 후 전경사진과 영업 상태를 먼저 저장합니다.
- 미진열 상품은 바코드/POS 모달로 모아서 처리하면 빠릅니다.
- 사진을 올린 뒤 미리보기를 확인합니다.
- 조사 종료 후에는 지역 엑셀, 사진 ZIP, 전체 백업을 내려받아 둡니다.
